# Excel workbook model (`build_xlsx.py`)

`scripts/build_xlsx.py model.json out.xlsx` renders this JSON, saves it, re-opens it with openpyxl and checks it (sheet shapes, no formulas, no error values). It exits non-zero on any problem.

```json
{
  "properties": {"title": "Báo cáo kiểm thử — PROJ-123"},
  "sheets": [
    {
      "name": "Results",
      "title": "Kết quả — PROJ-123",
      "meta": [["Ticket", "PROJ-123"], ["Kết luận", "NOT READY"]],
      "columns": [
        {"header": "Case", "width": 13},
        {"header": "Priority", "width": 9, "choices": "priority"},
        {"header": "Status", "width": 11, "choices": "status"},
        {"header": "Notes", "width": 45}
      ],
      "rows": [["TC-S1-001", "P0", "PASS", ""]],
      "blank_rows": 0,
      "freeze_header": true,
      "autofilter": true,
      "landscape": true
    }
  ]
}
```

- `name`: tab name, cut to 31 characters; `[]:*?/\` become `-`; duplicates get ` (2)`.
- `title` and `meta` (key/value lines) are optional and sit above the table. The header row is frozen and filtered wherever it lands.
- `columns`: a string or `{header, width, choices, wrap, align}`. `width` is in Excel character units (default 15). Text wraps by default (`"wrap": false` to turn off); `align`: `left` | `center` | `right`.
- `choices`: a dropdown on that column, as a list (no commas, ≤255 characters in total) or a preset: `status` (PASS FAIL BLOCKED SKIPPED), `uat` (Pass Fail), `severity`, `bug_status`, `priority`, `verdict`, `review`, `risk`.
- `rows`: lists of cells; numbers stay numbers. `\n` inside a string is a line break in the cell. Text starting with `=` is stored as text, never as a formula.
- `blank_rows`: empty bordered rows with the same dropdowns, for sheets people fill in (UAT, manual runs).
- Status colours: any table cell whose whole text is a status or severity (`PASS`, `FAIL`, `BLOCKED`, `SKIPPED`, `READY`, `NOT READY`, `READY WITH KNOWN ISSUES`, `APPROVED`, `CHANGES_REQUESTED`, `blocker` … `trivial`, `open`, `fixed`, `verified`, `reopened`, `wont_fix`, `duplicate`) gets the same fill as in the Word export, and the colour follows edits (conditional formatting).
- Print setup: A4, landscape unless `"landscape": false`, fit to one page wide, header row repeated on every printed page.
- Font Arial 10 (Vietnamese diacritics on every OS). Row heights are estimated from the text length, since Excel does not grow rows on its own for files written by a script.

## Sheet layouts per kind

Headers in `project.language`; IDs, statuses and severities in English.

### `cases`

Generated by `scripts/export_cases.py --to xlsx-model` (do not build it by hand): sheet `Cases` (ID, Stream, Title, Priority, Type, Requirement, Preconditions, Test data, Steps, Expected, Status, Notes — Status is an empty dropdown so the sheet works as a manual run checklist), sheet `Traceability` (Stream, Requirement, Source, Test cases), sheet `Streams` (Stream, Title, Cases). `--lang en` for English headers.

### `results`

One sheet `Results` with every case of every stream, so it can be filtered: `Case | Stream | Title | Priority | Status | Bug | Evidence | Notes`, widths `[13, 8, 35, 9, 11, 22, 30, 40]`, `choices` `priority` and `status`. Take the rows from `results/*.md` and the titles from `cases/*.md`. Add a sheet `Totals`: `Stream | Cases | PASS | FAIL | BLOCKED | SKIPPED` with one row per stream and a final total row (numbers computed by you, not formulas).

### `bugs`

One sheet `Bugs`: `ID | Title | Severity | Priority | Status | Ticket | Test case | Environment | Found at | Tracker | Summary`, widths `[22, 40, 10, 8, 10, 11, 12, 11, 11, 11, 50]`, `choices` `severity`, `priority`, `bug_status`. Sort by severity, then ID. One row per bug file in `qa/bugs/` whose `ticket` is the run (or all open bugs when the user asks for the full list). Steps to reproduce go in the Word export, not here.

### `report`

Sheets in this order, each one table:

1. `Summary` (`Tổng quan`): `title`, `meta` = ticket, title, environment + base URL, build, date, verdict; table = the totals per stream and overall.
2. `AC coverage`: `AC | Test cases | Result | Note`, `Result` with `choices: "status"`.
3. `Bugs`: as `bugs` above, without the Summary column.
4. `Blocked`: `Case | Reason | What unblocks it`.
5. `Results`: as `results` above.
6. `Questions`: `# | Question | For (PO/dev) | Answer`, with `blank_rows: 0`.

Screenshots are not embedded in Excel; the Evidence column holds the path relative to the run folder.
